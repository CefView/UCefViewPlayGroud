# UCefViewPlayGround

UCefViewPlayGround is a demo host project for the [UCefView](https://fab.com/s/ec232806c889) Unreal Engine plugin. This project includes a trial binary version of UCefView plugin. UCefView enables seamless integration of Chromium Embedded Framework (CEF) browser views within Unreal Engine projects.
